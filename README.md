# 📊 AMO CRM Priority Manager

Браузерное расширение (Chrome / Яндекс Браузер) для визуальной приоритизации клиентов в **amoCRM**.
Помогает менеджерам не терять важные сделки среди десятков задач в день, подсвечивая их прямо в интерфейсе.

## 🚀 Возможности

- **Умная подсветка сделок:** 13 статусов с разделением на группы (Активные, Действующие, Холодные, Архив).
- **Быстрая смена статуса:** панель выбора статуса при наведении на сделку (без открытия карточки).
- **Боковая панель (Sidebar):** статистика, поиск, фильтры и список клиентов поверх страницы (не сдвигает контент).
- **Автоматический сбор:** расширение само собирает сделки со страницы `/todo` в локальную базу.
- **Аналитика:** график распределения клиентов по статусам (Chart.js).
- **Темы оформления:** светлая, тёмная и системная.
- **Локализация:** поддержка русского и английского языков (i18n).
- **Экспорт / Импорт:** сохранение базы в JSON и загрузка из файла.
- **Wild-статус:** пометка компаний, которых нет в вашей БД (для чужих страниц).

## 🛠 Стек технологий

- **Язык:** TypeScript (строгая типизация, ООП-подход).
- **Сборка:** `tsc` (компиляция) + `esbuild` (бандлинг) + `cpx` (копирование ресурсов).
- **UI:** Vanilla JS (без фреймворков), CSS-переменные для тем.
- **Аналитика:** Chart.js.
- **Хранение:** `chrome.storage.local`.

## 📦 Установка и сборка

### Требования
- Node.js 18+
- npm 9+

### Шаги для разработки

1. Клонируйте репозиторий:

```bash
git clone https://github.com/your-username/amo-priority-manager.git
cd amo-priority-manager
```

2. Установите зависимости:

```bash
npm install
```

3. Соберите проект:

```bash
npm run build
```

4. Загрузите расширение в браузер:
    - Откройте `browser://extensions` (Яндекс Браузер) или `chrome://extensions` (Chrome).
    - Включите **«Режим разработчика»** (переключатель в правом верхнем углу).
    - Нажмите **«Загрузить распакованное расширение»**.
    - Выберите папку **`dist/`** (не корень проекта!).

### Команды для разработки

| Команда | Что делает |
|---------|-----------|
| `npm run build` | Полная сборка в `dist/` |
| `npm run watch` | Автосборка при изменении файлов |
| `npm run clean` | Очистка папки `dist/` |

### ⚠️ Важно

- Загружать в браузер нужно **только папку `dist/`**, а не корень проекта.
- После изменений в коде не забудьте выполнить `npm run build` и нажать «Обновить» в браузере.
- Если расширение не обновилось, перезагрузите страницу amoCRM (F5).

## 📋 Статусы клиентов

| Статус | Иконка | Группа | Описание |
|--------|--------|--------|----------|
| Новый | 🆕 | Активные | Свежий лид, с которым еще не было контакта |
| Горячий | 🔥 | Активные | Высокая вероятность покупки, клиент готов |
| Тёплый | 🤔 | Активные | Проявляет интерес, но не готов покупать сейчас |
| Действующий | ⭐ | Действующие | Постоянный клиент (в сопровождении) |
| Продление | 🔄 | Действующие | Действующий клиент, подошёл срок продления |
| Конкурент ПО | ⚔️ | Холодные | Пользуется аналогичным программным обеспечением |
| Конкурент-дилер | 🏷️ | Холодные | Купил продукт у другого дилера |
| После демо | 📉 | Холодные | Был отказ после проведения презентации |
| На старте | 🥶 | Холодные | Отказ при первом контакте |
| На уточнении | ❓ | Архив | Буфер для сомнительных случаев (требует проверки) |
| Мёртвый | 💀 | Архив | Недозвон, технический архив |
| Нецелевой | 🚫 | Архив | Нецелевой клиент, вывод из воронки |
| Wild | 🍒 | Специальный | Компания отсутствует в вашей БД (показывается только на чужих страницах) |
